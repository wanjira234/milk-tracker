# Static files for the public pages

Served at `/app/static/...` (needs `enableStaticServing = true` in `.streamlit/config.toml`).

- `img/` photos used on the Home and About pages. Check you have the right to use each one before the site is shown beyond the hackathon, or swap in your own photos (keep the same file names).
- `hero.mp4` (optional): a short, silent clip of cattle. If this file exists, the Home banner plays it in the background on desktop and tablets (never on small phones, to save data, and not for people who ask their device for reduced motion). Keep it under 5 MB, around 10 to 15 seconds, 1280x720, no sound. If it is missing, the banner shows a photo instead.
